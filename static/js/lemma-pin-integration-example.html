Lemma PIN Protection - Integration Example

How PIN Protection Works

  1. User confirms email (one-time)
  2. User creates 4-digit PIN (on first credential storage)
  3. PIN + browser fingerprint = encryption key
  4. Wallet encrypted with key, stored in localStorage
  5. Every visit: Enter PIN to unlock wallet
  6. Background verification continues (transparent)
  7. Auto-locks after 15 minutes of inactivity

Security Note

PIN is NEVER sent to the server. It's used purely client-side to derive an encryption key. Even if the server is compromised, your PIN remains safe.

Integration Code Example

Regular Flow (No PIN):

// User confirms email
// → Permission lemma issued
// → Stored in wallet (encrypted)
// → Shield checks permission (transparent)
// → Access granted

const wallet = new LemmaWalletWithPIN({ usePIN: false });
await wallet.storeCredential(permissionLemma);
// Done - no PIN prompt

With PIN (4-Factor Auth):

// User confirms email
// → Permission lemma issued
// → User creates 4-digit PIN
// → Wallet encrypted with PIN
// → Every visit: Enter PIN to unlock
// → Shield checks permission (transparent)
// → Access granted

const wallet = new LemmaWalletWithPIN({ usePIN: true });
await wallet.init();  // Prompts for PIN
await wallet.storeCredential(permissionLemma);
// PIN protects all credentials

Site Configuration:

// Site admin decides: Require PIN or not

// Option 1: PIN optional (recommended)
window.LEMMA_USE_PIN = true;  // Show PIN setup prompt
                               // User can skip

// Option 2: PIN required (high security)
window.LEMMA_USE_PIN = true;
window.LEMMA_PIN_REQUIRED = true;  // Cannot skip

// Option 3: No PIN (default flow)
window.LEMMA_USE_PIN = false;  // Standard encrypted wallet
