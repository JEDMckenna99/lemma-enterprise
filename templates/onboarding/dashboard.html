Quick Start

Add human verification to your website with just a few lines of code: 

// Install the Lemma SDK
npm install @lemma/sdk

// Initialize with your API key
import { LemmaVerification } from '@lemma/sdk';

const lemma = new LemmaVerification({
  apiKey: '{{ customer.api_key[:20] }}...'
});

// Verify users are human
const result = await lemma.verify();
if (result.isHuman) {
  // User verified!
  showProtectedContent();
}
