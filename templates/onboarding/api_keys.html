Quick Integration Examples

Environment Variables

Store your API key securely using environment variables:

# .env file
LEMMA_API_KEY={{ customer.api_key }}
LEMMA_INSTANCE_URL={{ request.url_root.rstrip('/') }}

cURL Example

Test your API key with a simple cURL request:

curl -X POST "{{ request.url_root.rstrip('/') }}/api/verify-human" \
  -H "X-API-Key: {{ customer.api_key }}" \
  -H "Content-Type: application/json" \
  -d '{"presentation": "your_credential_here"}'

JavaScript Fetch

Example API call using JavaScript fetch:

const response = await fetch('{{ request.url_root.rstrip('/') }}/api/verify-human', {
  method: 'POST',
  headers: {
    'X-API-Key': '{{ customer.api_key }}',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    presentation: yourCredential
  })
});

const result = await response.json();
console.log('Verification result:', result);
