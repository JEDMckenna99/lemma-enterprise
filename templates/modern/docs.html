Security Configuration Guide

Configure security levels and monitoring for your use case

Security Level Configuration

// Security Levels and Their Use Cases // LOW SECURITY - Content sites, blogs const shield = new LemmaBotShield({ securityLevel: 'low', backgroundChecks: false, checkOnEvents: ['comment', 'contact_form'] }); // MEDIUM SECURITY - E-commerce, SaaS platforms const shield = new LemmaBotShield({ securityLevel: 'medium', backgroundChecks: true, checkOnEvents: ['checkout', 'signup', 'sensitive_action'], maxFailures: 3, gracePeriod: 24 * 60 * 60 * 1000 // 24 hours }); // HIGH SECURITY - Financial services, healthcare const shield = new LemmaBotShield({ securityLevel: 'high', backgroundChecks: true, checkOnEvents: ['login', 'transfer', 'data_access'], maxFailures: 2, gracePeriod: 60 * 60 * 1000 // 1 hour }); // CRITICAL SECURITY - Gaming, high-value transactions const shield = new LemmaBotShield({ securityLevel: 'critical', backgroundChecks: true, checkOnEvents: ['any_action'], maxFailures: 1, gracePeriod: 0 // No grace period }); // CUSTOM INTERVALS - Fine-grained control const shield = new LemmaBotShield({ securityLevel: 'custom', customCheckInterval: 30 * 1000, // 30 seconds backgroundChecks: true });
