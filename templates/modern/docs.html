🔐 Authentication vs Verification

🔐 VERIFICATION (One-Time)

  • Creates new identity credentials
  • Uses Stripe KYC verification
  • ~500ms (includes document checks)
  • Server-side API calls

⚡ AUTHENTICATION (Ongoing)

  • Validates existing credentials
  • Rust/WASM cryptographic validation
  • ~1-50µs (offline operation)
  • Client-side SDK

🌐 Federated Network Integration

Users verify once with Stripe Identity, then access all network sites instantly. No re-verification needed.

JavaScript
// Initialize federated wallet const wallet = new LemmaFederatedWallet({ debug: false, networkRegistryUrl: 'https://lemma.id/api/network' }); await wallet.init(); // Check if user is already verified in the network if (await wallet.hasValidCredentials()) { // User already verified - instant access (offline) showProtectedContent(); console.log('✅ Network verification: ~5µs'); } else { // User needs verification - redirect to Stripe Identity window.location.href = '/verify'; }

🔗 Network Benefits

  • Cross-site access: Users verified on any Lemma site can access your content
  • Zero re-verification: No need to verify users who are already in the network
  • Offline operation: 99.9% of authentications happen offline (~1-50µs)
  • Privacy-preserving: Zero personal data storage with cryptographic proofs

Main class for bot protection and user verification.

TypeScript

🔗 REST API Reference

POST /api/sdk/start-identity-verification ~500ms

Start Stripe Identity KYC verification process

JavaScript
const response = await fetch('/api/sdk/start-identity-verification', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ returnUrl: 'https://yoursite.com/verified' }) }); const { sessionUrl } = await response.json(); window.location.href = sessionUrl; // Redirect to Stripe Identity
POST /api/sdk/complete-identity-verification ~50µs

Complete verification and receive identity credential

JavaScript
const response = await fetch('/api/sdk/complete-identity-verification', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ sessionId: 'stripe_session_id_from_callback' }) }); const { credential } = await response.json(); // Store credential in federated wallet await wallet.storeCredential(credential);
GET /api/network/client-config ~10ms

Get dynamic network configuration for client-side SDK

JavaScript
const config = await fetch('/api/network/client-config').then(r => r.json()); // Use config to initialize wallet const wallet = new LemmaFederatedWallet({ networkRegistryUrl: config.networkRegistryUrl, nodeId: config.nodeId });

💡 Integration Examples

🛒 E-commerce Checkout Protection

Protect checkout flows and prevent bot purchases while maintaining smooth UX for real users.

JavaScript
// E-commerce Integration const shield = new LemmaBotShield({ apiKey: 'your-api-key', apiBase: 'https://lemma.id', securityLevel: 'high', // High security for payments checkOnEvents: ['checkout', 'payment'] }); // Protect checkout button shield.protect('#checkout-btn'); // Verify before payment processing document.getElementById('checkout-btn').addEventListener('click', async (e) => { e.preventDefault(); const result = await shield.verifyUser(); if (result.verified && result.confidence > 0.8) { processPayment(); } else { showHumanVerification(); } });

🔒 Security Configuration

Configure security levels based on your application's risk profile:

Security Level Use Case Background Checks Grace Period
Low Content sites, blogs Disabled 7 days
Medium E-commerce, SaaS Enabled 24 hours
High Financial, healthcare Continuous 1 hour
Critical Gaming, high-value Real-time None
JavaScript
// Security level examples // LOW SECURITY - Content sites, blogs const shield = new LemmaBotShield({ securityLevel: 'low', backgroundChecks: false, checkOnEvents: ['comment', 'contact_form'] }); // MEDIUM SECURITY - E-commerce, SaaS platforms const shield = new LemmaBotShield({ securityLevel: 'medium', backgroundChecks: true, checkOnEvents: ['checkout', 'signup', 'sensitive_action'], maxFailures: 3, gracePeriod: 24 * 60 * 60 * 1000 // 24 hours }); // HIGH SECURITY - Financial services, healthcare const shield = new LemmaBotShield({ securityLevel: 'high', backgroundChecks: true, checkOnEvents: ['login', 'transfer', 'data_access'], maxFailures: 2, gracePeriod: 60 * 60 * 1000 // 1 hour });
