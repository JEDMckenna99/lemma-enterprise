Early access pricing

Three separate concepts — don't mix them up:

  • IDV verification (paid, pass-through): first-time identity check via Stripe Identity — currently $2/person. The relying site or user pays at checkout; lemma.id adds no platform fee.
  • Local proof check (free): routine verify() calls that validate an existing credential in-browser — no paid server call per check.
  • Site integration (free in early access): API keys, dashboard, site-block controls, and hosted platform features.

Recommended use: trigger IDV only on suspicious or high-risk actions, not every signup. Users who already hold a credential reuse it for free local checks.
