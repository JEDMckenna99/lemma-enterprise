Frequently Asked Questions

How can you be so much cheaper than Auth0?

Architecture. Auth0 runs servers for every verification - their costs scale with your users. Lemma verifies client-side using cryptographic credentials - after we issue a credential, verifications are free. Our costs don't scale, so yours don't either.

Is $5/month really unlimited?

Yes. Unlimited users, unlimited verifications, unlimited sites. $5/month flat. No per-user fees, no overage charges, no surprises.

What's a "PoH Partner" (Trusted Verifier)?

If you already verify user IDs (KYC, Stripe Identity, etc.), you can become a PoH Partner. We'll issue Proof-of-Human credentials for your verified users - free. Your users get portable credentials, you help grow the network.

When do I need Full PoH ($2/user)?

Only if you don't already verify IDs and want us to handle it. This includes government ID document verification + liveness detection. One-time fee per user - no monthly charges. If you already do KYC, use the free Partner tier instead.

How does verification work client-side?

Users hold cryptographic credentials in their browser. When they authenticate, the credential is verified locally using Ed25519 signatures - no server call needed. Takes 36-47 microseconds vs 200-500ms for server-based auth.

Is it as secure as Auth0?

More secure. Ed25519 cryptographic signatures can't be forged. Built-in replay protection via nonces. No central session store to breach. Credentials are tamper-proof and user-held.

Can I start free and upgrade later?

Yes. Start with the free tier (1,000 users). When you need more, upgrade to Pro ($5/month). Your users and credentials carry over seamlessly.

What if I have 100,000+ users?
