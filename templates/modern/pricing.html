Frequently Asked Questions

Is Lemma IAM really free forever?

Yes, completely free forever. Email-based authentication with cryptographic credentials, OAuth integration, and built-in bot friction - all free with no user limits. No credit card required.

How does PoH Federation work?

If you already verify user IDs (KYC, Stripe Identity, etc.), we federate your verification for FREE. Your verified users get Proof-of-Human credentials they can use across the network. You help grow the network, we handle the credential infrastructure.

When should I pay for Full PoH Verification?

Pay the $1.50 one-time fee per user only if you don't already do ID verification and want Lemma to handle it. This includes full government ID document verification + liveness detection. If you already verify IDs, use the free federation tier instead.

How does $1.50 compare to Stripe Identity?

Same price as Stripe Identity ($1.50 per verification). But with Lemma you ALSO get: free IAM system, cross-site credential portability, microsecond verification, and the user can reuse their credential across the network.

Do users need to verify every time they visit?

No! Users verify once and get a cryptographic credential in their wallet. All subsequent verifications happen in microseconds without user interaction. Works across all sites in the network.

What's included in the free IAM tier?

Everything you need: email-based authentication, client-side credentials, OAuth 2.0 ("Sign in with Lemma"), catch-all email blocking, microsecond verification, and built-in bot friction through email + persistence requirements.

How fast is verification?

Lemma verifies credentials in microseconds (~36-47µs) - that's 1000x faster than server-call authentication. Verification happens locally without network round-trips.

What's the difference between IAM and PoH?

IAM (Free): Email-based authentication with bot friction. Good for most sites.
PoH (Proof-of-Human): Verified human identity via ID document check. For maximum bot protection where you need to ensure each account is a unique human.

Why is IAM free?

IAM uses client-side credential storage - users hold their own credentials, not our servers. This means our infrastructure costs are minimal. Free IAM grows the network, which increases the value of PoH credentials.

Can I start with IAM and upgrade to PoH later?

Yes! Start with free IAM. If you later need ID verification, you can upgrade to Full PoH ($1.50/MAU) or federate your own verification for free. Your existing users keep their IAM credentials.

What makes Lemma different from Auth0/Okta?

Cost: IAM is FREE (vs $0.48-$2/MAU)
Speed: 1,000x faster verification (microseconds vs hundreds of milliseconds)
Architecture: Client-side credentials vs server-side sessions
Bot Protection: Built-in vs requires add-ons

Are there any contracts or commitments?

No! IAM is free with no commitments. For Full PoH, you pay $1.50 one-time per user verified - no monthly fees, no recurring charges.
