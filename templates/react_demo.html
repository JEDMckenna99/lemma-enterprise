🛠️ How to Integrate These Components

These React components work seamlessly with your existing Flask templates. Here's how to use them:

Option 1: Data Attributes (Automatic)

<div data-lemma-component="DashboardMetrics"></div>
<div data-lemma-component="MetricCard" 
     data-lemma-props='{"title": "Verifications", "value": 847392}'></div>

Option 2: JavaScript API

// Mount specific components
LemmaComponents.mount('OfflineVerificationDemo', 'demo-container');

// Mount with props
LemmaComponents.mount('MetricCard', 'metric-1', {
  title: 'Response Time',
  value: '8.3ms',
  icon: 'clock'
});
