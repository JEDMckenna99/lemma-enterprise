Quick Start Guide

Get up and running with Lemma verification in under 10 minutes. This guide will walk you through the essential steps to integrate human verification into your application.

1

Get Your API Key

Sign up and get your API key from the onboarding console.

X-API-Key: your_api_key_here
2

Verify a Human

Make a simple API call to verify that a user is human.

curl -X POST {{ request.host_url }}api/verify-human \ -H "X-API-Key: your_api_key_here" \ -H "Content-Type: application/json"
3

Integrate with Your App

Add the verification check to your application logic.

if (response.verified && response.isHuman) { // User is verified human allowAccess(); }
