Authentication

Operational
v2.7.0

All API requests require authentication using an API key in the header.

Header Format

X-API-Key: {{ customer_api_key }}

cURL Example

curl -H "X-API-Key: {{ customer_api_key }}" \
     {{ request.host_url }}api/health

API Key Security

Keep your API key secure and never expose it in client-side code. Use environment variables or secure configuration management.

Verification Endpoints

Operational
v2.7.0

Verify Credential

POST

Verify a Lemma credential presentation

POST /api/verify-credential

Request Body

JSON 
{
  "presentation": {
    "@context": ["https://www.w3.org/2018/credentials/v1"],
    "type": ["VerifiablePresentation"],
    "verifiableCredential": [...]
  },
  "challenge": "random_challenge_string"
}

Response

JSON 
{
  "success": true,
  "verified": true,
  "isHuman": true,
  "message": "Credential verified successfully"
}

Verify Human

POST

Complete human verification and set session

POST /api/verify-human 
curl -X POST -H "Content-Type: application/json" \
     -H "X-API-Key: {{ customer_api_key }}" \
     {{ request.host_url }}api/verify-human

Code Examples

JavaScript / Node.js

// Basic verification check
async function verifyWithLemma(credential, challenge) {
  const response = await fetch('/api/verify-credential', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-API-Key': 'your_api_key_here'
    },
    body: JSON.stringify({
      presentation: credential,
      challenge: challenge
    })
  });
  
  const result = await response.json();
  return result.verified;
}

Python

import requests

def verify_lemma_credential(credential, challenge, api_key):
    """Verify a Lemma credential"""
    response = requests.post(
        'https://your-domain.com/api/verify-credential',
        headers={'X-API-Key': api_key},
        json={
            'presentation': credential,
            'challenge': challenge
        }
    )
    
    if response.status_code == 200:
        return response.json().get('verified', False)
    return False
