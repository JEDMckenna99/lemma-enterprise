Introduction

The Lemma API allows you to integrate human verification into your applications. This documentation covers the endpoints and methods available for verifying human credentials and managing verification sessions.

Authentication

All API requests require CSRF protection. You'll need to:

  1. Obtain a CSRF token using the /api/get-csrf-token endpoint
  2. Include the token in subsequent requests using either:
    • The X-CSRF-Token header
    • A csrf_token field in the JSON body

API Endpoints

GET /api/get-csrf-token

Get a CSRF token for API requests.

Response

{
    "csrf_token": "random_token_string"
}
POST /api/verify-human

Verify a human presentation and establish a verified session.

Request Parameters

Parameter Type Description
presentation object The verifiable presentation object containing the human credential
challenge string The challenge string to prove presentation ownership

Example Request

{
    "presentation": {
        "type": ["VerifiablePresentation"],
        "verifiableCredential": [{
            "type": ["VerifiableCredential", "HumanCredential"],
            "issuer": "did:lemma:issuer",
            "credentialSubject": {
                "id": "did:lemma:user123",
                "type": "Human"
            }
        }],
        "proof": {
            // ... proof details
        }
    },
    "challenge": "random_challenge_string",
    "csrf_token": "your_csrf_token"
}

Success Response

{
    "success": true,
    "message": "Human verification successful",
    "redirect": "/protected",
    "user_id": "user123"
}

Error Response

{
    "success": false,
    "error": "Error message details"
}
POST /api/store-credential

Store a verified credential in the session.

Request Parameters

Parameter Type Description
user_id string The user's identifier
credential object The verifiable credential object

Example Request

{
    "user_id": "user123",
    "credential": {
        "type": ["VerifiableCredential", "HumanCredential"],
        "issuer": "did:lemma:issuer",
        "credentialSubject": {
            "id": "did:lemma:user123",
            "type": "Human"
        },
        "proof": {
            // ... proof details
        }
    }
}

Success Response

{
    "success": true,
    "message": "Credential stored successfully",
    "redirect": "/protected"
}

Integration Guide

To integrate Lemma verification into your site:

  1. Initialize your application with the Lemma client library
  2. Request a CSRF token when your application starts
  3. When verification is needed:
    • Direct users to verify their humanity at your-lemma-instance/verify?user_id=USER_ID
    • Once verified, they'll receive a credential in their Lemma wallet
    • Use the credential to verify their humanity on your site
  4. Implement the verification flow using the API endpoints documented above

Security Considerations

  • Always use HTTPS for API requests
  • Include CSRF tokens in all POST requests
  • Validate all responses on your server
  • Store credentials securely
  • Implement proper session management
