Quick Usage Guide

CSS Components

Simply add the CSS class to any HTML element:

/* Basic usage */ <div class="card-enhanced">...</div> <button class="btn btn-primary">...</button> <div class="status-card success">...</div>

React Components

Add data attributes and components auto-mount:

/* Auto-mounting via data attributes */ <div data-lemma-component="StatusCard" data-lemma-props='{"type": "success", "title": "..."}'> </div>
