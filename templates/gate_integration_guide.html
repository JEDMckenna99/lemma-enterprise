Lemma Gate Integration Guide

Complete guide to integrating Lemma Gate protection

Quick Start

1. Include Lemma Scripts

<script src="https://your-lemma-instance.com/static/js/lemma-gate.js"></script>

2. Add Gate Protection

<div data-lemma-gate="true">
  <!-- Your protected content here -->
  <h2>Premium Content</h2>
  <p>This content requires human verification.</p>
</div>

3. Initialize (Optional)

<script>
  LemmaGate.init({
    apiEndpoint: 'https://your-lemma-instance.com',
    theme: 'default',
    showBranding: true
  });
</script>

Configuration Options

Option Type Default Description
apiEndpoint string current domain Lemma API endpoint URL
theme string 'default' UI theme: 'default', 'minimal', 'custom'
showBranding boolean true Show "Powered by Lemma" branding
autoInit boolean true Automatically initialize gates on page load

Advanced Usage

Custom Verification Handler

LemmaGate.onVerification = function(result) {
  if (result.verified) {
    console.log('User verified:', result.userId);
    // Custom logic for verified users
  } else {
    console.log('Verification failed:', result.error);
    // Handle verification failure
  }
};

Programmatic Gate Control

// Check if user is verified
if (LemmaGate.isVerified()) {
  // Show premium content
}

// Manually trigger verification
LemmaGate.verify().then(result => {
  if (result.verified) {
    // User is now verified
  }
});

Multiple Gates

<div data-lemma-gate="premium" data-gate-level="premium">
  Premium content
</div>

<div data-lemma-gate="basic" data-gate-level="basic">
  Basic protected content
</div>
