isHuman Proof Network Demo

Verify once. Prove locally across sites.

Follow one user across two businesses. The user verifies once, carries a private human proof in their browser wallet, and each business checks that proof locally without storing ID documents.

This demo uses Stripe Identity as the prototype IDV rail. Lemma provides the reusable credential, wallet, site-private PPID derivation, local verification, and revocation layer. Commercial deployment requires an approved IDV-provider path.
User Gets one reusable isHuman proof and keeps it in the browser wallet.
Ticketing Site Checks proof locally before allowing a protected ticket action.
SaaS Trial Checks the same human but receives a different PPID.
Operator Blocks one site PPID or escalates severe abuse for review.

Why each party should care

User

  • Verify once instead of repeating CAPTCHA or ID checks.
  • Keep the credential in a browser wallet they control.
  • Show different private site IDs to different businesses.

Business

  • Receive a simple human verdict before high-abuse actions.
  • Avoid storing passports, selfies, or raw IDV data.
  • Block a bad site-private ID instantly if trust is broken.

IDV Provider

  • One verification becomes useful across many web flows.
  • Reach customers that cannot justify full IDV per signup.
  • Enable reuse without observing every site presentation.

Business before and after

Without Lemma

  • CAPTCHA slows real users while attackers route around it.
  • Full IDV is too expensive and invasive for most flows.
  • Businesses either tolerate abuse or store risky PII.

With Lemma

  • Sites get `human`, `privateSiteId`, and `reason`.
  • Proof checks run locally after setup.
  • Operators can block locally or escalate severe abuse.
