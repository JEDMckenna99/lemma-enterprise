What is Lemma?

Lemma is a human verification service that uses decentralized identity to verify humans once, and allow them to prove their humanity across multiple sites without re-verification.

The Lemma API Widget makes it easy to add human verification to your website or application.

Basic Integration

Here's how to add the Lemma API Widget to your site:

<!-- 1. Add the Lemma script to your page --> <script src="https://your-lemma-instance.com/static/js/lemma-api-widget.js"></script> <!-- 2. Add a container for the widget --> <div id="lemma-widget-container"></div> <!-- 3. Initialize the widget --> <script> document.addEventListener('DOMContentLoaded', function() { LemmaWidget.init({ containerId: 'lemma-widget-container', callbackUrl: '/your-callback-url', onSuccess: function(result) { console.log('Verification success:', result); document.getElementById('verification-result').textContent = 'Verification successful! User ID: ' + result.user_id; } }); }); </script> <!-- 4. Display verification results --> <div id="verification-result"></div>

Advanced Options

Basic Configuration Options

LemmaWidget.init({ containerId: 'lemma-widget-container', // ID of the container element userId: 'user_abc123', // Optional: Specific user ID to use callbackUrl: '/your-callback-url', // URL to redirect after verification buttonText: 'Verify Human', // Custom button text description: 'Verify you are human', // Custom description text shouldRedirect: false // Prevent automatic redirect });

Callback Functions

LemmaWidget.init({ containerId: 'lemma-widget-container', onSuccess: function(result) { console.log('Verification successful:', result); // Handle successful verification }, onFailure: function(error) { console.error('Verification failed:', error); // Handle verification failure } });

HTML Data Attributes

You can also configure the widget using HTML data attributes:

<div id="lemma-container" data-lemma-widget data-lemma-user-id="user_abc123" data-lemma-callback="/your-callback" data-lemma-button-text="Verify Human" data-lemma-description="Complete verification to access this content" ></div>

The widget will automatically initialize for elements with the data-lemma-widget attribute.

Direct API Access

You can also use the Lemma API directly without the widget UI:

// Call the verification function directly window.proveALemma({ userId: 'user_abc123', callbackUrl: '/your-callback-url', elementId: 'status-element-id', // Optional: element to update with status shouldRedirect: true, onSuccess: function(result) { console.log('Verification success:', result); }, onFailure: function(error) { console.error('Verification failed:', error); } });
