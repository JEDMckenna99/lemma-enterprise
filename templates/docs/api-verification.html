Server-Side Verification

While the SDK handles client-side verification automatically, these endpoints are available for server-side verification when needed.

Verify Credential

POST /api/verify-credential

Request

JSON
{ "credential": { "id": "cred_...", "type": ["VerifiableCredential", "..."], "issuer": "did:lemma:...", "proof": {...} } }

Response

JSON
{ "valid": true, "checks": { "signature": true, "expiration": true, "revocation": true, "issuer_trust": true } }

Revocation Status

GET /api/revocation/check/{credential_id}

Check if a specific credential has been revoked.
