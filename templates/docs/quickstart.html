Quick Start

Add passwordless authentication to your site with 1 script tag and 3 backend endpoints. No API keys required. No configuration. The SDK handles everything.

What you'll build

A complete sign-in flow where users authenticate with a passkey on lemma.id, and your site receives a pseudonymous ID (PPID) to identify them. No passwords, no OAuth tokens, no user data to store.

Step 1: Add the SDK

Include the Lemma SDK from the CDN. Always serves the latest version.

HTML
<script src="https://lemma.id/sdk/lemma-wallet.js"></script>

That's it. No npm install, no API keys, no configuration files.

Step 2: Add Sign-In (Frontend)

The entire frontend integration is 10 lines:

JavaScript
const wallet = new LemmaWallet(); async function signIn() { const result = await wallet.getAuthenticatedPPID(); if (result.authenticated) { // Send the PPID to YOUR backend - this is the user's ID for your site await fetch('/api/auth/lemma', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ ppid: result.ppid }) }); // User is signed in! } else { // Redirect to lemma.id for wallet unlock (first time only) wallet.unlockWithRedirect({ returnUrl: window.location.href }); } }
What happens under the hood

First visit: User redirects to lemma.id, taps their passkey, gets a signed credential (lemma) stored in your site's IndexedDB. Takes ~2 seconds.
Every visit after: The SDK verifies the stored credential locally with Ed25519. Zero network calls. Takes <5ms.

Step 3: Handle the PPID (Backend)

Your backend receives a PPID (Pairwise Pseudonymous ID) - a unique, site-specific identifier for the user. Use it like you'd use a Google OAuth ID or email address.

Python (Flask)
@app.route('/api/auth/lemma', methods=['POST']) def lemma_auth(): ppid = request.json.get('ppid') # Look up or create user by PPID user = db.query(User).filter_by(lemma_ppid=ppid).first() if not user: user = User(lemma_ppid=ppid) db.add(user) db.commit() session['user_id'] = user.id return jsonify({'success': True})
Node.js (Express)
app.post('/api/auth/lemma', async (req, res) => { const { ppid } = req.body; // Look up or create user by PPID let user = await User.findOne({ lemma_ppid: ppid }); if (!user) { user = await User.create({ lemma_ppid: ppid }); } req.session.userId = user.id; res.json({ success: true }); });
Ruby (Rails)
def lemma_auth ppid = params[:ppid] user = User.find_or_create_by(lemma_ppid: ppid) session[:user_id] = user.id render json: { success: true } end

Step 4: Auto-Sign-In on Page Load

Check if the user is already authenticated when the page loads. For return visitors, this completes in under 5ms with zero network calls.

JavaScript
// On page load const wallet = new LemmaWallet(); const result = await wallet.getAuthenticatedPPID(); if (result.authenticated) { // User already signed in - show authenticated UI console.log('Welcome back! PPID:', result.ppid); await fetch('/api/auth/lemma', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ ppid: result.ppid }) }); } else { // Show sign-in button document.getElementById('sign-in-btn').style.display = 'block'; }

That's It

Your users can now sign in with a passkey. No passwords to hash, no OAuth to configure, no MFA to implement, no user emails to store.
