v4.0.0 (Current)

January 2026

Features

  • lemma.id-first architecture - credentials stored in the user's lemma.id
  • Passkey protection for lemma.id unlock
  • Local Ed25519 signature verification
  • Pairwise identifiers (PPIDs) for privacy
  • Bloom filter revocation checking
  • Cross-device lemma.id linking via QR code

Breaking Changes

  • Removed OAuth flow (replaced by lemma.id redirect)
  • Removed session-based auth (now stateless)
  • Changed credential format to W3C Verifiable Credentials

v3.0.0

October 2025

  • Added OPRF-based credential issuance
  • Improved revocation performance
  • Added TypeScript definitions

v2.0.0

July 2025

  • Initial public release
  • OAuth-based authentication
  • Basic credential verification
