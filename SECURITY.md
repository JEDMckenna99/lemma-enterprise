# Security Policy

## Supported Versions

The `main` branch is the supported branch for coordinated security fixes.

## Reporting a Vulnerability

If you believe you found a security issue in Lemma.id:

1. Do not open a public issue with exploit details.
2. Email `security@lemma.id` with:
   - summary and impact
   - affected endpoint/module
   - reproduction steps or proof-of-concept
   - suggested remediation (optional)
3. Include "SECURITY" in the subject line.

## Response Targets

- Initial acknowledgement: within 3 business days
- Triage decision: within 7 business days
- Fix timeline: depends on severity and exploitability

## Responsible Disclosure

- Please allow us reasonable time to investigate and patch before public disclosure.
- We will coordinate release notes and credit where appropriate.
- Reports that include clear reproduction details are prioritized.

## Out of Scope

- Social engineering attacks
- Denial-of-service requiring unrealistic traffic/resources
- Issues in third-party dependencies without a Lemma.id-specific exploit path
