- **P2P networks** (Napster, Gnutella) - Decentralized file sharing

#### **Why They Failed:**
```

❌ No practical public-key cryptography for masses
❌ Devices too weak for client-side crypto
❌ No formal verification tools
❌ Internet infrastructure too primitive
```

#### **Projects That Tried:**
- **Bitcoin** - Decentralized money
- **Ethereum** - Decentralized computing
- **IPFS** - Decentralized storage
- **Solid** (Tim Berners-Lee) - Personal data stores
- **Diaspora** - Decentralized social media

#### **Why They Failed:**
```
Web3 Problems (2010s):
❌ Terrible user experience (private keys, gas fees)
❌ No formal verification of security properties
❌ Scalability issues (7 TPS for Bitcoin)
❌ Energy consumption concerns
❌ Speculation focus over utility
❌ No bridge to existing internet
```

**Specific Failures:**
- **Blockchain**: Too slow, expensive, energy-intensive
- **Solid**: No cryptographic guarantees, complex setup
- **Diaspora**: No network effects, technical complexity
- **IPFS**: Storage only, no authentication/permissions
