# @lemma.id/proof-verifier

Local-first verifier for [Lemma proofs](https://lemma.id).

```sh
npm install "@lemma.id/proof-verifier@1.4.2"
```

On PowerShell, keep the quotes — `@lemma.id` is parsed incorrectly otherwise.

```js
import { createVerifier } from "@lemma.id/proof-verifier";
```

Zero-install alternative:

```js
import { createVerifier } from "https://lemma.id/sdk/proof-verifier.mjs";
```

Legacy names (`@lemma/ishuman-verify`, `/sdk/lemma-ishuman-verify.mjs`) are deprecated aliases.
