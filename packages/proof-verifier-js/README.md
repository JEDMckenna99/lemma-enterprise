# @lemma/proof-verifier

Local-first verifier for [Lemma proofs](https://lemma.id).

```sh
npm install @lemma/proof-verifier
```

```js
import { createVerifier } from "https://lemma.id/sdk/proof-verifier.mjs";
```

Legacy names (`@lemma/ishuman-verify`, `/sdk/lemma-ishuman-verify.mjs`) remain supported as deprecated aliases.
