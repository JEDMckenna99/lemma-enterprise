🛡️ Lemma Shield Widget Integration

Simple copy-paste integration for any website

📋 How to Integrate

Step 1: Include the Lemma scripts in your page

Step 2: Wrap your protected content in a div with id="protected-content"

Step 3: Initialize the widget with one line of JavaScript

Step 4: That's it! The widget handles everything else automatically

📄 Complete Integration Code

<!-- Include Lemma scripts --> <script src="https://your-lemma-instance.com/static/js/lemma-wallet.js"></script> <script src="https://your-lemma-instance.com/static/js/lemma-shield-widget.js"></script> <!-- Your protected content --> <div id="protected-content"> <!-- This content will be hidden until user verifies --> <h2>🎉 Premium Content</h2> <p>This content is only visible to verified humans!</p> </div> <!-- Initialize the widget --> <script> document.addEventListener('DOMContentLoaded', function() { const shield = new LemmaShieldWidget({ protectedContent: '#protected-content', apiBase: 'https://your-lemma-instance.com', onVerified: () => console.log('User verified!'), onError: (error) => console.error('Error:', error) }); }); </script>

⚙️ Configuration Options

const shield = new LemmaShieldWidget({ // Required: Selector for content to protect protectedContent: '#protected-content', // Optional: API base URL (defaults to current domain) apiBase: 'https://your-lemma-instance.com', // Optional: Security level (basic, standard, high, maximum) securityLevel: 'standard', // Optional: Custom widget container selector widgetContainer: '#lemma-shield-widget', // Optional: Callbacks onVerified: () => console.log('Access granted!'), onError: (error) => console.error('Error:', error), onStepChange: (step) => console.log('Step:', step), // Optional: UI customization showBranding: true, animationDuration: 300 });
