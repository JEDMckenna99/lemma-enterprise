# Lemma.id Standalone Commercial Packaging

Date: 2026-02-15

## Packaging Position

Lemma.id standalone offering:
- local authorization runtime (data plane)
- managed issuance/revocation/key governance (control plane)

## Suggested Tiers

### Starter
- Best-effort support
- Basic auth and revocation integration
- Community documentation

### Business
- Standard support window
- Operator runbooks and drill templates
- Conformance suite and deployment guidance

### Enterprise
- Contracted uptime and response targets
- Priority support and incident escalation
- Security/compliance package and custom rollout support

## Support Boundaries

- Covered:
  - token issuance/revocation workflows
  - auth contract conformance
  - deployment and runbook usage
- Not covered:
  - custom application logic bugs outside integration boundary
  - unmanaged third-party infra outages
