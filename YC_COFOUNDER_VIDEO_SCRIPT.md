**Format:** Two founders, conversational back-and-forth  
**Target Length:** 60 seconds

## 🎬 **TWO-PERSON VIDEO SCRIPT (60 Seconds)**

### **SETUP:**
- Both founders on camera (side-by-side or split screen)
- Founder 1 (F1): Technical founder
- Founder 2 (F2): Business/product founder
- Natural conversation, not scripted-sounding

---

## 📝 **COMPLETE SCRIPT:**

```
[F1]: Hi YC, I'm [Name] and this is [Co-founder Name]. We built 
Lemma - authentication that's 100x cheaper than Auth0.

[F2]: Current auth systems are expensive because they need API 
calls for login, session management, and every permission check. 
For 100,000 users, that's $2,000 a month in Auth0 fees.

[F1]: We realized auth doesn't need server calls. We use Ed25519 
signatures for client-side verification. The user's browser does 
the crypto - 31 microseconds, zero server cost, works offline.

[F2]: Plus, we use Bloom filters for revocation checks, so we 
never know which credentials users are validating. Complete privacy.

[F1]: We've built a full IAM system with email-based login, 
permission management, and cryptographic revocation. The beta 
is ready to launch.

[F2]: The auth market is $20 billion. We can undercut Auth0 by 
67% on price while being 1,000x faster.

[F1]: We've been building this for 5 months and we're looking 
for YC's help to scale this to enterprises.

[F2]: Thanks for watching.
```

**Word Count:** ~170 words  
**Speaking Pace:** 170 words/min = 60 seconds ✅

## 🎥 **FILMING TIPS FOR TWO PEOPLE:**

### **Setup Option 1: Side-by-Side**
```
[F1]  [F2]
 👤    👤
```
- Both visible at same time
- Natural conversation
- Shows chemistry

### **Setup Option 2: Split Screen**
```
[F1] | [F2]
👤   | 👤
```
- Each person has own frame
- Clearer individual presence
- Easier to film remotely

### **Setup Option 3: Pass the Camera**
```
[F1 speaks] → [Camera pans] → [F2 speaks]
```
- More dynamic
- Shows energy
- Requires practice

**Recommendation:** Side-by-side (easiest, most natural)
